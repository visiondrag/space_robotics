# Tools and data access

## Simulation
| Tool | What it is |
|---|---|
| [OmniLRS](https://github.com/OmniLRS/OmniLRS) | Photorealistic lunar robotics simulator on NVIDIA Isaac Sim. Real DEMs refined procedurally to about 2.5 cm/px, multi-robot, synthetic data pipeline, ROS 1/2 bindings. From University of Luxembourg (SpaceR) and Tohoku University. [Paper](https://arxiv.org/abs/2309.08997) |
| [Isaac Sim](https://github.com/isaac-sim/IsaacSim) | Open-source NVIDIA Omniverse robot simulation app |
| [Gazebo](https://gazebosim.org/) | General robotics simulator, common for rover work |
| [SmallSatSim](https://arxiv.org/pdf/2603.14598) | GPU-accelerated microgravity robotics toolkit |

## Flight software
| Tool | What it is |
|---|---|
| [Space ROS](https://space.ros.org/) ([docs](https://space-ros.github.io/docs/rolling/Introduction/About-Space-ROS.html)) | Open-source fork of ROS 2 hardened for safety-critical space robotics, aligned with DO-178C and NPR 7150.2. NASA's FFR mission standardises on it. BSD 3-clause. |
| [NASA cFS](https://cfs.gsfc.nasa.gov/) | Core Flight System |
| [F Prime](https://fprime.jpl.nasa.gov/) | JPL flight software framework |
| [SPICE toolkit](https://naif.jpl.nasa.gov/naif/toolkit.html) | Ephemeris and geometry |
| [JPL Open Source Rover](https://github.com/nasa-jpl/open-source-rover) | Build-it-yourself rover (verify link) |
