# Mars32K, MarsData-V2 and Mars-Bench

- **Mars32K**: 32,368 unlabeled colour images from Curiosity's Mastcam (Aug 2012 – Nov 2018): mountains, valleys, craters, dunes, rocky terrain. Useful for self-supervised pre-training.
- **MarsData-V2**: 8,390 labeled 512×512 Mastcam images for rock segmentation. [GitHub](https://github.com/CVIR-Lab/MarsData)
- **Mars-Bench**: 20 datasets (classification, segmentation, object detection) on craters, cones, boulders, frost, using orbital and surface imagery, with baselines. [Paper](https://arxiv.org/abs/2510.24010)
- Related: [GMSRI texture-based rock dataset](https://pmc.ncbi.nlm.nih.gov/articles/PMC8399451/)
